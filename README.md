# Kellervorrat

Passwortgeschützte Web-App: <https://lehmheld-afk.github.io/kellervorrat-0add59/>

Der Seiteninhalt ist verschlüsselt (AES-256, StatiCrypt) und nur mit dem
Zugangspasswort lesbar. Erzeugt und veröffentlicht wird automatisch aus einem
lokalen Obsidian-Vault – bitte nicht von Hand bearbeiten.
